# ch10-process-loading-and-memory-layout

## Purpose
- Describe how the OS loads an executable and maps it into virtual memory.

## Outline
1. Loader responsibilities
2. Virtual memory fundamentals
3. Text, data, heap, stack layout

- Typical process layout and growth directions.
- Dynamic linker responsibilities during startup.
- mmap usage for shared objects and anonymous memory.

## Key terms
- virtual memory
- program header
- dynamic linker
- mmap
