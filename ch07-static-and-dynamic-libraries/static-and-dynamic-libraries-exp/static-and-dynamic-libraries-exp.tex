\section{Experiment: Static and Dynamic Libraries}

\subsection{Objective}
Create, use, and compare static and dynamic libraries in C programs.

\subsection{Setup Requirements}
\begin{itemize}
\item GCC compiler
\item ar (archiver)
\item Linux environment
\end{itemize}

\subsection{Part 1: Creating a Static Library}

Create source files and build the library:

\begin{lstlisting}[language=bash]
gcc -c math_lib.c -o math_lib.o
ar rcs libmath.a math_lib.o
ar -t libmath.a
\end{lstlisting}

\subsection{Part 2: Using a Static Library}

Link against the static library:

\begin{lstlisting}[language=bash]
gcc main.c -L. -lmath -o static_program
./static_program
\end{lstlisting}

\subsection{Part 3: Creating a Shared Library}

Build a shared library with PIC:

\begin{lstlisting}[language=bash]
gcc -fPIC -c math_lib.c -o math_lib_pic.o
gcc -shared math_lib_pic.o -o libmath.so
\end{lstlisting}

\subsection{Part 4: Using a Shared Library}

Link and run with shared library:

\begin{lstlisting}[language=bash]
gcc main.c -L. -lmath -o shared_program
LD_LIBRARY_PATH=. ./shared_program
\end{lstlisting}

\subsection{Part 5: Comparing Sizes}

Compare static vs dynamic linking:

\begin{lstlisting}[language=bash]
ls -l static_program shared_program
ldd static_program
ldd shared_program
\end{lstlisting}

\subsection{Questions for Reader}

\begin{enumerate}
\item What are the advantages of static linking?
\item What are the advantages of dynamic linking?
\item Why is position-independent code required for shared libraries?
\item How can you verify which library is being used at runtime?
\end{enumerate}
