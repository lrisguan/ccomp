# ch04-assembly-and-object-files

## Purpose
- Explain how assembly is turned into relocatable object files and what those objects contain.

## Outline
1. Role of the assembler
2. Object file structure overview
3. Symbol table basics
4. Section layout (.text, .data, .bss, .rodata)
5. Relocatable object semantics

## Content plan
- Assembler responsibilities and encoding rules.
- Object file as a container for code, data, symbols, and relocations.
- Symbol table entries and binding.
- Section semantics and how the linker interprets them.
- Relocatable vs executable differences at this stage.

## Key terms
- object file
- section
- symbol table
- relocation
