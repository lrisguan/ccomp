\chapter{Assembly and Object Files}

\section{Outline}
\begin{enumerate}

  \item Object file structure overview
  \item Symbol table basics
  \item Section layout (.text, .data, .bss, .rodata)
  \item Relocatable object semantics
\end{enumerate}

\begin{itemize}

  \item Object file as a container for code, data, symbols, and relocations.
  \item Symbol table entries and binding.
  \item Section semantics and how the linker interprets them.
  \item Relocatable vs executable differences at this stage.
\end{itemize}

\section{Key Terms}

\end{itemize}
